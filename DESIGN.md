# AntiGPT Mobile visual direction

Reading this as an Android chat tool for people who connect their own model gateway: a quiet, restrained interface with a clear reading order.

- **Dials:** ENERGY 1, RHYTHM 2, MOTION 1.
- **Palette:** near-black canvas, two slate surfaces, readable warm-white text, and one mineral-teal accent. Red is reserved for errors.
- **Identity motif:** a narrow teal response rail marks assistant output and repeats as the short rule in the empty state. It marks where generated text begins rather than decorating every surface.
- **Typography:** Android system sans for interface and conversation text; monospace appears only in code. Weight, size, and spacing carry hierarchy.
- **Composition:** chat gives messages room to read; history compresses into a scan-friendly list; settings use labeled fields with direct help text.
- **Motion:** no route animation. A small activity indicator communicates generation; it does not animate other content.
- **Accessibility:** use native text fields and pressables, visible labels, scalable text, generous touch areas, and contrast that meets WCAG AA for text.
